YelpCamp is a full-stack web application for discovering, creating, and reviewing campsites — built to practice production-grade patterns in a MERN-adjacent stack (Node.js, Express, MongoDB, EJS). It implements secure user authentication and authorization, full CRUD for campground listings, interactive location mapping via MapTiler, image uploads through Cloudinary, and a review/rating system with proper access control.
Key features:
🔐 Session-based auth with route-level authorization (only owners can edit/delete their listings)
🗺️ Interactive maps with geocoding via MapTiler
🖼️ Multi-image upload and storage via Cloudinary
⭐ User reviews and star ratings per campground
✅ Server-side validation with Joi schemas
🎨 Responsive UI with Bootstrap/EJS templating
Tech stack: Node.js · Express · MongoDB · Mongoose · EJS · Bootstrap · Cloudinary · MapTiler
